# 담당자 질문과 답변

실제 과제 폴더에서 질문과 담당자 답변 원문을 모으는 선택적 틀이다. 아래 빈 항목은 실제 질문·답변이 아니다.

초기 업무 파악부터 하네스 구성 이후와 구현·검증 중까지 계속 추가할 수 있다. 모든 답변을 받는 것이 계획·하네스 구성이나 작업 착수의 전제는 아니다.

## 사용 원칙

- AI는 먼저 문서·데이터·기존 답변을 확인하고, 그곳에서 알 수 없으며 문제 해결의 결정에 실제로 영향을 주는 질문만 작성한다. 과제 안내가 반드시 담당자에게 확인하도록 명시한 항목은 포함한다. 단순 호기심·중복·과제 밖 기능·현재 불필요한 가상 상황은 제외하고, 후속 질문은 작업 중 필요해질 때 추가한다. 사용자도 궁금한 질문을 자유롭게 추가한다. 질문별 출처·상태·우선순위·AI 정리 칸은 만들지 않는다.
- 질문에는 번호를 붙이고 한 항목에 질문 하나를 적는다. 기존 번호와 사용자가 적은 질문·답변을 임의로 바꾸지 않는다.
- 사용자가 담당자에게 질문하고 아래 답변 칸에 원문을 입력한다. 답변이 있으면 응답받은 항목이며, 빈칸은 아직 응답받지 않은 항목이다. AI는 답변을 대신 채우지 않는다.
- Codex는 사용자가 읽으라고 요청했을 때 답변을 반영한다. 필요한 추가 확인만 짧게 알리고, 답변에 없는 정책을 확정하지 않는다. 별도 정리·상태 갱신을 반복하지 않는다.
